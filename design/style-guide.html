SQLMedium#07

Which customers have never placed an order?

 query.sql-- customers(id, name)   orders(id, customer_id, total)
SELECT c.name
FROM customers c
LEFT JOIN orders o ON o.customer_id = c.id
WHERE o.id IS NULL;
Correct. A LEFT JOIN keeps every customer; unmatched rows have NULL order columns.
Not quite. An INNER JOIN drops customers with no orders, so it can't find them.
Hint. Which join keeps rows that have no match?
